## ข้อจำกัดของต้นแบบ (ตั้งใจให้เป็นแบบนี้)

- **ข้อมูลเก็บในเบราว์เซอร์เครื่องนี้เท่านั้น** ยังไม่ได้ต่อ Supabase → อีกคนยังไม่เห็นข้อมูลกัน
- **รูปของงานเก่าไม่มี** เห็นเป็นชื่อไฟล์ 📁 เพราะไฟล์จริงยังอยู่ใน Google Drive
- ยังไม่มี: สำรองข้อมูลอัตโนมัติ · ทำงานตอนเน็ตหลุด · ติดไอคอนบนหน้าจอมือถือ (PWA)
- **ล้างประวัติเบราว์เซอร์แล้วข้อมูลหาย** — ยังไม่ต้องใช้บันทึกงานจริง

### เรื่องกล้อง
เปิดจากไฟล์ในเครื่อง (`file://`) Chrome จะยอมให้เปิดกล้อง แต่ถ้าไม่ยอม ให้กดที่ช่องรูปแล้วเลือกไฟล์ภาพแทน — ตอนขึ้น cloud จริงจะได้ HTTPS แล้วกล้องจะทำงานเต็มที่ทุกเครื่อง

## ที่ผมล้างให้ตอนนำเข้าข้อมูลเก่า

**ลวดลาย** — ท่าโร่ → ทาโร่ · สี่เสส → สี่เสา · สามหว่ง → สามห่วง · ก้นหอยสองสี → ก้นหอย 2 สี · โซ่กล่องสีทอง → โซ่กล่อง

**วิธีซ่อม** — เลเซอร์ / ยิงเลเซอร์ / เชื่อมเซอร์ / เลเซอร์ปิด → **เชื่อมเลเซอร์** · เชื่อมเลเซอร์,ไฟ / เชื่อมเลเซอร์และไฟ → **เชื่อมเลเซอร์ + เชื่อมไฟ**

**อาการชำรุด** — แยกเป็น *ลักษณะ* + *ตำแหน่ง* อัตโนมัติ (เช่น "ขาดใกล้หัวจรวด" → ขาด / ใกล้หัวจรวด) แถวที่แยกไม่ได้ 13 แถวจะได้ลักษณะ "อื่น ๆ" และเก็บข้อความเดิมไว้ในหมายเหตุ

**อื่น ๆ** — 1 แถวมี path รูปหลุดมาอยู่ในช่องวิธีซ่อม ล้างออกให้แล้ว
