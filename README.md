# บันทึกงานซ่อม — Goldsmith Specialist

เว็บแอปบันทึกงานซ่อมเครื่องทอง สำหรับผู้ใช้ 2 คน พร้อมหน้ารายงาน KPI
ทำงานบนมือถือเป็นหลัก บันทึกได้แม้ไม่มีเน็ต

**แทนที่:** Google Sheets + AppSheet + รูปใน Google Drive

---

## โครงสร้าง

| โฟลเดอร์ | คืออะไร |
|---|---|
| `app/` | ตัวแอป — **นี่คือสิ่งที่ Cloudflare Pages เอาไปเผยแพร่** |
| `setup/schema.sql` | โครงฐานข้อมูล Supabase (รันครั้งเดียวตอนติดตั้ง) |
| `backup/` | สคริปต์ดึงข้อมูล+รูปกลับลงคอมเครื่องนี้ |
| `docs/ติดตั้ง.md` | **คู่มือติดตั้งทีละขั้น — เริ่มอ่านที่นี่** |
| `prototype/` | ต้นแบบรุ่นแรก เปิดจากไฟล์ในเครื่องได้เลย ไม่ต้องต่อ cloud |

## เทคโนโลยี

HTML + CSS + JavaScript ล้วน **ไม่มี build step ไม่มี npm ไม่ต้องติดตั้ง Node**
เรียก Supabase ผ่าน REST API ตรง ๆ ด้วย `fetch` — `git push` แล้วขึ้นเว็บได้ทันที

| ชั้น | ใช้อะไร | ค่าใช้จ่าย |
|---|---|---|
| หน้าเว็บ + HTTPS | Cloudflare Pages | ฟรี |
| ฐานข้อมูล + รูป + ล็อกอิน | Supabase | ฟรี |
| เก็บโค้ด + สั่ง deploy | GitHub (private) | ฟรี |

## ไฟล์ในโฟลเดอร์ app

| ไฟล์ | หน้าที่ |
|---|---|
| `config.js` | **ไฟล์เดียวที่ต้องแก้ตอนติดตั้ง** — URL + anon key ของ Supabase |
| `api.js` | คุยกับ Supabase (ล็อกอิน / ตาราง / รูป) |
| `store.js` | เก็บข้อมูลในเครื่อง + คิวรอส่งตอนเน็ตหลุด |
| `app.js` | หน้าจอทั้งหมด |
| `migrate.html` | นำเข้าข้อมูลเก่า 123 รายการ + รูป (ใช้ครั้งเดียว) |
| `sw.js` | ทำให้เปิดแอปได้ตอนไม่มีเน็ต |

## หลักการที่ยึดไว้

- **เขียนลงเครื่องก่อนเสมอ แล้วค่อยส่งขึ้น cloud** — เน็ตหลุดกลางคันไม่มีข้อมูลหาย
- **อัปรูปให้เสร็จก่อนค่อยส่งแถวข้อมูล** — ไม่มีแถวที่ชี้ไปยังรูปที่ไม่มีอยู่
- **ไม่ลบอะไรจริง** — งานที่ลบคือซ่อน (`deleted = true`) กู้คืนได้เสมอ
- **ทุกการแก้ไขจดประวัติ** ว่าใครแก้ช่องไหนเมื่อไหร่
- **ส่วนต่างน้ำหนักคำนวณในฐานข้อมูล** ไม่ใช่ในแอป — รายงานเชื่อถือได้แม้แอปมีบั๊ก
