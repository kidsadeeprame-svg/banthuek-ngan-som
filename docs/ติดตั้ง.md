# คู่มือติดตั้ง — บันทึกงานซ่อม

ทั้งหมดนี้ทำจากเบราว์เซอร์ **ไม่ต้องติดตั้งโปรแกรมอะไรบนคอมเครื่องนี้เลย**
(ใช้ Git ที่มีอยู่แล้วอย่างเดียว)

เวลาที่ใช้ทั้งหมดประมาณ **40–60 นาที** ทำทีละขั้นตามลำดับ

---

## ภาพรวม

```
คุณแก้โค้ด ──git push──> GitHub ──อัตโนมัติ──> Cloudflare Pages
                                                  │  (หน้าเว็บ + HTTPS ฟรี)
                                    มือถือ 2 เครื่อง ─┘
                                        │
                                        ▼
                                    Supabase  (ข้อมูล + รูป + ล็อกอิน ฟรี)
                                        │
                            backup.ps1 ──┘  ดึงกลับลงคอมเครื่องนี้ทุกวัน
```

**ค่าใช้จ่าย ฿0** ทั้ง GitHub, Cloudflare Pages และ Supabase ในระดับที่เราใช้ ไม่มีขั้นตอนไหนขอบัตรเครดิต

## ขั้นที่ 3 — สร้างโปรเจกต์ Supabase

1. ไป <https://supabase.com/dashboard> → **Sign in with GitHub** (ใช้บัญชีที่เพิ่งสร้าง)
2. **New project**
   - Name: `banthuek-ngan-som`
   - Database Password: กดปุ่มสุ่มแล้ว **เก็บไว้ที่ปลอดภัย** (ใช้ตอนกู้ระบบเท่านั้น ไม่ใช้ประจำวัน)
   - Region: **Southeast Asia (Singapore)** ← ใกล้ไทยที่สุด เร็วกว่าที่อื่นมาก
   - Create new project แล้วรอประมาณ 2 นาที

### 3.1 สร้างตาราง

1. เมนูซ้าย → **SQL Editor** → **New query**
2. เปิดไฟล์ `setup\schema.sql` ในโฟลเดอร์นี้ ก๊อบทั้งไฟล์ไปวาง
3. กด **Run** — ต้องขึ้น *Success. No rows returned*

### 3.2 สร้างผู้ใช้ 2 คน

1. เมนูซ้าย → **Authentication** → **Users** → **Add user** → *Create new user*
2. คนที่ 1
   - Email: `user1@banthuek.local`
   - Password: **PIN 6 หลักที่จะใช้จริง** เช่น `481920`
   - ติ๊ก **Auto Confirm User** ← สำคัญ ไม่ติ๊กจะล็อกอินไม่ได้
3. ทำซ้ำสำหรับคนที่ 2: `user2@banthuek.local` + PIN ของอีกคน

> **ทำไม PIN ต้อง 6 หลัก:** Supabase บังคับรหัสผ่านอย่างน้อย 6 ตัวอักษร
> และ 6 หลักปลอดภัยกว่า 4 หลักถึง 100 เท่า (1 ล้านความเป็นไปได้ แทนที่จะเป็น 1 หมื่น)
> ตรงนี้ต่างจากที่คุยกันไว้ว่า "4-6 หลัก" — ระบบจริงต้องเป็น 6

### 3.3 คัดลอกค่าเชื่อมต่อ

เมนูซ้าย → **Project Settings** → **Data API** เก็บ 2 ค่านี้ไว้

| ค่า | หน้าตา |
|---|---|
| **Project URL** | `https://abcdefghijklmnop.supabase.co` |
| **anon public key** | ข้อความยาว ๆ ขึ้นต้นด้วย `eyJ...` |

> anon key **ไม่ใช่ความลับ** ออกแบบมาให้ฝังในหน้าเว็บ ตัวที่กันข้อมูลจริงคือ RLS + การล็อกอิน
> แต่ **service_role key ห้ามเอามาใช้เด็ดขาด** — อันนั้นข้าม RLS ได้ทุกอย่าง

## ขั้นที่ 4 — ใส่ค่าเชื่อมต่อลงในแอป

เปิดไฟล์ `app\config.js` แก้ 2 บรรทัดนี้

```js
SUPABASE_URL:      'https://abcdefghijklmnop.supabase.co',
SUPABASE_ANON_KEY: 'eyJhbGciOi...',
```

ถ้าอยากเปลี่ยนชื่อที่แสดงบนหน้าล็อกอิน แก้ตรง `USERS` ได้ (แต่ `email` ต้องตรงกับที่สร้างใน Supabase)

แล้วส่งขึ้น GitHub

```powershell
git add app/config.js
git commit -m "ใส่ค่าเชื่อมต่อ Supabase"
git push
```

## ขั้นที่ 5 — เปิดเว็บด้วย Cloudflare Pages

1. ไป <https://dash.cloudflare.com/sign-up> สมัครด้วยอีเมลเดียวกัน (ยืนยันอีเมลด้วย)
2. เมนูซ้าย → **Workers & Pages** → **Create** → แท็บ **Pages** → **Connect to Git**
3. อนุญาตให้ Cloudflare เข้าถึง GitHub แล้วเลือก repo `banthuek-ngan-som`
4. หน้า Set up builds and deployments ตั้งดังนี้

   | ช่อง | ใส่ว่า |
   |---|---|
   | Framework preset | **None** |
   | Build command | **เว้นว่าง** |
   | Build output directory | `app` |

5. **Save and Deploy** รอ 1–2 นาที
6. จะได้ URL เช่น `https://banthuek-ngan-som.pages.dev` ← **นี่คือแอปของคุณ**

ตั้งแต่นี้ไป ทุกครั้งที่ `git push` Cloudflare จะ deploy ให้เองภายในไม่ถึงนาที

## ขั้นที่ 7 — ติดตั้งบนมือถือ

**Android (Chrome)** — เปิด URL → เมนู ⋮ → *เพิ่มลงในหน้าจอหลัก*
**iPhone (Safari)** — เปิด URL → ปุ่มแชร์ → *เพิ่มไปยังหน้าจอโฮม*

จะได้ไอคอนเหมือนแอปจริง เปิดแล้วไม่เห็นแถบที่อยู่ และ **เปิดได้แม้ไม่มีเน็ต**

ครั้งแรกของแต่ละเครื่องต้องออนไลน์เพื่อล็อกอิน หลังจากนั้นจำไว้ให้ ไม่ต้องล็อกอินซ้ำ

## ขั้นที่ 8 — ตั้งให้สำรองอัตโนมัติลงคอมเครื่องนี้

### 8.1 ตั้งค่าสคริปต์

1. ในโฟลเดอร์ `backup\` คัดลอก `backup-config.example.json` → เปลี่ยนชื่อเป็น **`backup-config.json`**
2. เปิดแก้ใส่ `supabaseUrl`, `anonKey`, `email`, `pin` ให้ตรงกับที่ตั้งไว้
3. ทดลองรัน: คลิกขวาที่ `backup.ps1` → **Run with PowerShell**
   ต้องได้ CSV + โฟลเดอร์ `photos` โผล่ใน `backup\data\`

> ไฟล์ `backup-config.json` มี PIN อยู่ข้างใน — ผมกันไม่ให้ขึ้น GitHub ไว้แล้วใน `.gitignore`

### 8.2 ตั้งให้รันทุกวัน (ไม่ต้องใช้สิทธิ์ admin)

1. กด Windows → พิมพ์ **Task Scheduler** → เปิด
2. ขวามือ → **Create Task** (ไม่ใช่ Create Basic Task)
3. แท็บ **General**
   - Name: `สำรองข้อมูลงานซ่อม`
   - เลือก **Run only when user is logged on** ← เลือกอันนี้จะไม่ต้องใช้สิทธิ์ admin
4. แท็บ **Triggers** → New → Daily → เวลา **18:00** → OK
5. แท็บ **Actions** → New
   - Program/script: `powershell.exe`
   - Add arguments:
     ```
     -NoProfile -ExecutionPolicy Bypass -File "C:\Users\kidsadee.kae\Goldsmith Specialist\01-Method\App บันทึกงานซ่อม\backup\backup.ps1"
     ```
6. แท็บ **Conditions** → เอาติ๊ก *Start the task only if the computer is on AC power* ออก
7. OK

## เรื่องที่ต้องรู้ไว้

**Supabase ฟรีจะพักโปรเจกต์ถ้าไม่มีใครใช้ 7 วันติด**
ใช้ทุกวันอยู่แล้วจึงไม่มีปัญหา แต่ถ้าหยุดยาว ครั้งแรกที่เปิดจะช้าประมาณ 30 วินาที (ปลุกอัตโนมัติ ไม่ต้องทำอะไร)

**พื้นที่เก็บรูป 1 GB**
รูปย่อ 30 KB + รูปดู 180 KB ต่อ 1 ภาพ → ประมาณ 800 งานเต็ม
ถ้าใกล้เต็ม ให้ลบรูป `.view.jpg` ของปีเก่าออกจาก Supabase → Storage
(รูปย่อยังอยู่ แอปยังเห็นภาพ และไฟล์เต็มมีสำรองในคอมเครื่องนี้แล้ว)

**2 คนแก้งานเดียวกันพร้อมกัน**
คนที่กดบันทึกทีหลังจะทับของคนแรก แต่ประวัติการแก้ไขจดไว้ทั้งคู่ว่าใครแก้อะไรเมื่อไหร่
ด้วยคน 2 คนที่นั่งใกล้กัน โอกาสชนกันแทบไม่มี

**การลบงาน**
ระบบไม่ลบจริง แค่ซ่อน (`deleted = true`) กู้คืนได้เสมอผ่าน Supabase → Table Editor

| อาการ | สาเหตุที่พบบ่อย |
